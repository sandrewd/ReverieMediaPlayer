# Visualisations that render nothing WITHOUT AN EXTERNAL TEXTURE.
#
# 39 presets, each verified to render at 0% with no texture directory and to come
# back with a stand-in image in place. Reverie deliberately ships no textures - see the
# README for why a texture is a far easier thing for a hostile upstream to alter than a
# media file - so in a stock install these are black and are hidden.
#
# This list is applied ONLY when no texture directory was found. Someone who installs a
# texture pack into ~/.local/share/reverie/textures gets all 39 back automatically,
# because for them the presets are not broken at all.
#
# Measured, not read. Every preset in the pack was rendered for six seconds with audio playing and
# its highest non-black fraction recorded. Anything at or below 2% was re-rendered ONE AT A TIME on
# an idle machine, because a reading taken while several workers compete is depressed by contention
# - that second pass exonerated 67 of 345 candidates, one in five, so a single parallel reading is
# not evidence. Survivors were then rendered a third time with stand-in textures supplied, which is
# what splits this list from its companion.
#
# DO NOT ADD BY READING A PRESET. "Planet escher - cubesBW", whose missing-texture warning started
# the whole investigation, looks texture-dependent and renders black with its texture as well as
# without. Measure both ways:
#
#   tools/scan-presets.sh -l <shortlist> -o out.tsv -j 1
#   tools/scan-presets.sh -l <shortlist> -o out.tsv -j 1 -t <dir of stand-in images>
#
# The four presets in "! Transition" are left out of both lists. They are transitions *to black*
# doing exactly what they say, and every place a preset is offered already excludes that category.
#
# Paths are relative to the preset root and match the curated install and the full pack alike.
