# Visualisations that use an external image, and which images they ask for.
#
# 1866 presets. Tab-separated: the preset's path, then the names it wants, comma-separated.
#
# The names are what Milkdrop asks for after the sampling-mode prefixes (fw_, fc_, pw_, pc_ and
# their reversed spellings) are removed - those set wrap and filter modes and are not part of any
# filename. A name of the form randNN or randNN_prefix is not a filename at all: projectM reads it
# as "any image from the pool", or "any image whose filename begins with prefix". See
# TextureManager::GetRandomTexture.
#
# WHY THE NAMES ARE HERE. Reverie marks a preset whose image is missing. Whether it is missing can
# only be answered against the machine it is running on, and answering it by reading every preset
# in the pack costs 3.35s from a cold cache against the 115ms the whole index takes. With the names
# shipped, the runtime lists the texture directory once - one readdir - and knows exactly which
# presets are satisfied. Drop an image in and the mark goes away; the answer is never stale and
# nothing has to be remembered between launches.
#
# Regenerate with tools/list-texture-presets.py. Paths are relative to the preset root.
